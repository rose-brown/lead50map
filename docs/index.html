1. .env 파일 생성 및 키 입력

아래 경로의 .env 파일에 Kakao Developers에서 발급한 키를 입력하세요.

cp .env.example .env
# .env 파일 경로:
# /Users/hkeum/.gemini/antigravity/scratch/apt-commute-map/.env
# VITE_KAKAO_JS_KEY=자바스크립트_키
# KAKAO_REST_API_KEY=REST_API_키

2. Kakao Developers 필수 체크

  • [제품 설정] → [카카오맵] → 사용 설정 ON
  • [앱 설정] → [앱] → [플랫폼 키] → [JavaScript 키] → JavaScript SDK 도메인에 http://localhost:5173 및 https://rose-brown.github.io 등록

3. 다른 시/구 추가 & 1회 캐시 실측

이미 측정된 단지는 data/kakao_transit_cache.json에 영구 저장되어 재호출되지 않습니다. 

python3 scripts/fetch_kb_regions.py --regions "서울 양천구,경기 의왕시"
python3 scripts/enrich_kakao.py
